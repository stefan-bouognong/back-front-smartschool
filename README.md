ce projet contient deux dossier smartschool-back et smartschool-front

pour lancer, il suffit de naviguer dans chaque dossier et de taper la commamde npm run dev

le dossier du backend contient les donnees du .env pour la connection a la base de donnee et la connection a campay pour le payement.
